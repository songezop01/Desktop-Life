# 貓咪與房間更新 0.4

依橘色長毛貓參考改善原創向量角色：杏仁眼、虎斑、頰毛、奶油色胸腹、腳趾與沿尾巴彎曲的環紋。四肢交錯步態區分支撐與抬腳階段，跑步增加步幅；耳朵、瞳孔、眼瞼與頭部會隨動作和視線改變。維持可連續變形的向量角色，本次不是參考插畫的逐幀重製。

## 接觸與吊球

- 接地姿勢統一於角色視窗 local Y=144；呼吸與頭部動作不把腳掌整體抬離平台。
- 拖曳釋放後持續更新姿勢，落地清除空中姿勢。
- 吊球使用固定 43 DIP 繩長的阻尼擺；貓咪從跳台下層靠近，球在爪子可及範圍內才伸爪施力。爪尖與碰撞使用同一目標位置。
- 陪玩在地面玩具和吊球間輪替；球不在範圍時等待擺回。複雜家具組合的多段導航仍屬後續項目。

## 驗證方式

核心測試涵蓋擺動方向、繩長、阻尼、長幀穩定、平台支撐與離開平台。WPF 冒煙測試另外使用真實視窗與自行渲染的圖像，檢查落腳像素、空中姿勢解除、從下層跳台撥球及爪尖接觸、45 度旋轉方塊的透明邊界、原生視窗排序。

實際結果追加於 VALIDATION.md。上述檢查不取代混合 DPI、多螢幕、不同顯示卡或長時間使用驗收。
