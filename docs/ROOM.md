# 陪伴房間 0.3

共用 GravityBody 使用固定上限時間步與細分步進，提供重力、邊界、地板、單向家具平台與斜坡。寵物落地不反彈；玩具落地反彈逐步耗散，低速停止抖動。圓球與方塊以圓形接觸體近似碰撞，支援動量交換；按下位置決定點擊方向，拖曳拋出採游標釋放速度。

RoomState 保存家具 ID、種類與座標、基本玩具位置。房間最多 24 件，舊存檔預設空房間。家具固定，編輯模式可移動、右鍵移除；一般模式點擊穿透。新增玩具獨立視窗接受拖曳，且都可被角色追逐。

可放貓跳台、溜滑梯、書桌、書架、睡墊、毛線球、鈴鐺球、玩具老鼠。平台承接寵物和玩具，斜坡加速滑動。角色可跳至接近、垂直距離約 185 點內的平台；高處可經中間平台，亦可手動抱上去。尚非任意房間障礙物的完整路徑搜尋，櫃子內部和桌腿不作實心牆碰撞。

玩具接觸改為側面站位、爪尖動畫、接近後施力；角色下半身亦會擋開滾入的玩具。摸頭出現人手，梳理出現梳子。原桌寵四級顯示套用到全部家具和玩具。

主控台 X 預設送到托盤，也可選保存並結束。托盤「結束」強制走真正退出流程；測試也使用相同退出入口。長期圖示基準與 pending 復原旗標分開，恢復後保留基準；使用者能更新，前一版留作 `.previous`，舊 `.restored` 可遷回。

驗證：167 項單元測試，包含四向點擊、落地反彈收斂、平台承接／移除後下落、斜坡滑行、碰撞傳遞、長期備份復用／更新／舊檔回復及房間相容。隔離 WPF 測試實際驗證角色下落、左右點擊事件、八種物件建立與保存、X 送托盤仍保留桌寵、四級視窗排序，並渲染自有美術供目視檢查。

實際多日房間遊玩、所有桌面縮放組合與任意家具密集布局仍需使用驗收。此次沒有為測試而重新移動使用者的真實圖示。
