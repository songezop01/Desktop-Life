# 陪伴房間 0.5

- 存檔：驗證後原子替換，保留三代備份；主檔損毀時嘗試有效備份並保存損毀原件。較新版本存檔拒絕降版覆蓋。控制台提供匯出與匯入，匯入在完整結束後重新啟動生效，不修改桌面圖示備份。
- 導航：依平台建立可達路徑，利用中繼平台上樓；先蹲再跳，落地稍作緩衝，跳躍期間延後切換行為。下樓先離開平台邊緣，靠牆時選另一側出口。不可達目標不瞬移。
- 顯示：可選擇房間所在顯示器，讀取該螢幕 DPI。切換螢幕、工作區變更或移除螢幕時重新安置家具與玩具。房間位置連同原工作區保存。全螢幕偵測只針對所選螢幕。
- 音效：[音效包管理與格式](SOUND_PACKS.md)，支援分類音量及即時切換。
- 美術：維持原四足骨架與 144 DIP 接觸基準，增加轉身過渡、背面、蹲坐、側躺、舔爪洗臉及前後肢伸展連段。自主洗臉用貓爪；使用者梳毛與摸頭才出現梳子與手。

## 驗證與界線

Windows Release 建置、單元測試及隔離資料的 WPF smoke 覆蓋存檔、平台落地、吊球伸爪接觸、方塊旋轉透明邊距、視窗排序及角色渲染。新增損毀／多代復原、匯入、音效格式、路徑與負座標／DPI 座標測試。角色新姿態檢查 100% 與 150% 渲染的地面接觸像素。

多螢幕採「一個房間、一個所選螢幕」，尚未支援自由跨螢幕拋接。座標測試不等於不同實體螢幕混合 DPI、熱拔插與顯示卡組合的驗收。播放器檢查不等於實際聽感驗收。平台導航仍採單向落腳平面，並非完整家具碰撞體或通用三維尋路。

此次沿用原創向量美術，可隨 DPI 清晰縮放，未導入參考插圖或未授權素材；沒有宣稱完成水彩毛流貼圖。下一步可做經授權的分層毛流貼圖與骨架動畫，先測試 100/125/150/200% 清晰度、記憶體與幀時間。
