# 音效包

0.5 可在控制台匯入、切換、試聽、移除音效包，不需要重新啟動。匯入會複製到本機音效庫，原始資料夾不受影響。移除只刪除庫內副本。總音量、貓咪音量與玩具音量立即生效；安靜陪伴與靜音仍優先。

準備資料夾，內含 `pack.json` 與至少一個 `Meow.wav`、`Purr.wav`、`Bell.wav`。缺少的種類使用內建音效。範例：

```json
{
  "Name": "我的貓咪音效",
  "Author": "填寫素材作者",
  "License": "填寫素材授權及來源",
  "Version": 1
}
```

只接受 PCM WAV、單聲道或立體聲、8–96 kHz、8/16/24/32 bit，每檔最多 10 MB、30 秒。會檢查格式、區塊及檔案長度；任一檔案不合格便拒絕整包。播放器無法解碼時會提示並回退內建聲音。

作者與授權欄位是來源記錄，不代表程式驗證了授權。請使用自己錄製或已取得使用權的聲音。內建聲音由程式合成。舊版 `audio-v1/custom` 可繼續使用，建議改為匯入正式音效包管理。

環境音分類暫未提供音源，控制項停用；女孩沒有角色聲音。
