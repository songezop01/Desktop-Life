# Desktop Life 0.12 開發進度

狀態：開發里程碑，尚非可安裝的 0.12 發行。開發版標識為 `0.12.0-preview.1`；正式電腦安裝與 GitHub v0.11.1 保持原有驗收結果，0.12 程式碼放在 `codex/012` 隔離分支。

## 本輪實作

- 食物附著於家具 ID，有限存量、料理批次及每口版本核對；貓、狗與女孩分別限制可吃的食物。空盆、過期批次、重複事件或已移除家具不可補飽。
- 同一場景執行緒共同套用扣糧與角色需求，之後放入同一個不可變存檔快照。schema 8 需要有效食物欄位；舊 schema 2–7 升級成空庫存，原檔與備份保留，離線不會自行扣糧。
- 食盆與餐桌可直接選飼料／五種料理；新增家具立即接線，無須先拖曳。角色飢餓時先尋找可用、可達且在進食範圍內的食物，接近途中不扣糧；實際落地、進食姿勢與接觸位置成立後才扣一份。隱藏、暫停、佈置、移除或换菜會釋放／失效預約。
- 進階／診斷新增短測 10 分鐘、長測 120 分鐘、停止與檢視報告。使用目前程式的雜湊核對副本及全新合成資料，隔離程序可繼續執行；重新開啟控制台可接回進度。結果保存後先等待程序確實退出，再通知完成；停止與中斷不當作通過。
- 樓梯步頻改按實際二維路程；平地採水平距離。拖動、瞬移、空中與非行走樣本不累積步距，保留既有導航支撐與恢復流程。
- 舊角色照顧右鍵、托盤照顧及控制台照顧對象／五個按鈕已移除；三角色的改名、記憶與狀態入口保留。舊程式入口只提供操作說明，不能直接增加需求或親密度。
- 接近角色時顯示透明插畫小手；游標停著沒有收益，真正撫摸才結算。新增可拖曳的插畫梳子，只在髮絲／毛皮接觸及有效移動後梳理；放開、Escape、切換佈置、隱藏或暫停會取消並收回。角色被其他視窗遮住時不能隔著視窗照顧。
- 貓跳台吊球新增可點選／拖撥的命中區。貓與狗依自己的可達站位接觸同一顆球，狗仍不能爬跳台；玩具活動只累計實際接觸時間，不將一次接觸補成整秒活動。
- 食盆飼料、五種餐桌料理、梳子與小手已使用透明插畫資產。餐桌附近椅子若對不準，女孩可站在真正可接觸的桌邊進食，仍逐口扣庫存。
- 動作呈現原型加入兩個模擬位置間的有界內插、16 階落脚時序與貼圖實際足點校準；暫停、隱藏、佈置及重定位會清除呈現回呼。此項仍在原生圖片／連續性驗收，不能宣稱動畫已通過或實測 60 FPS。
- 跨樓層家具活動必須走完最後路線才進入工作階段，避免在餐桌旁提前停步、仍帶著移動旗標而無法實際進食。有限食物回歸保留移位家具、上下樓及手機縮放的真實支撐驗證。
- 隔離壓測加入三角色有限進食、真實時間撫摸／梳理、貓狗吊球接觸、空盆補充及取消事件證據；達到首次覆蓋後輪換重複輸入。缺少覆蓋不可通過；不週期性重設需求或直接發放獎勵。

## 驗證界線

本輪使用建置、核心／持久化／程序通訊單元測試，以及數秒的隔離原生元件檢查。這些不是 600 秒短壓測、7200 秒長測或 Standard／Full 發行通過。個別失敗嘗試與修正後報告留在忽略的本機 `artifacts/verification/0.12`，不提交角色資料到 Git。

2026-10-09 本機證據：App Release 建置零警告／錯誤；整合單元測試 694 / 694 通過（含食物庫存／遷移、12 項程序通訊、22 項步距）；`--food-test` 的 20 項原生元件檢查通過，約 5.9 秒。原生診斷通訊約 13 秒，涵蓋斷開父端輸出管線、停止、重新連線、等待真退出、崩潰與報告重開；該次尚為變更開發版標識之前的建置，沒有把它當作新安裝包驗收。

2026-10-10 開發證據：整合單元測試 784 / 784 通過；85 / 85 發行門檻合約案例通過，包含缺少互動覆蓋／不一致食物計數必須拒絕。食物元件 22 項、直接互動 15 項及吊球子項 12 項原生檢查通過；新吊球截圖中的完整球與爪尖已實際檢視。移位家具、有限進食及多樓層支撐的原生小屋回歸通過。

目前連接的主螢幕 125% 與 spacedesk 副螢幕 175% 各自 1／2／3 層原生檢查通過，涵蓋 HWND 座標／DPI／工作區、角色足底、摸頭與梳子拖放、食物左鍵選單。此證據對應目前的橫向螢幕配置；未進行手機實際拔插、旋轉或休眠。樓梯畫面連續性仍有失敗案例，修正後必須重跑；加速的圖片矩陣與真實顯示回呼分開記錄，不能宣稱矩陣實測螢幕 FPS。

三分鐘隔離場景預檢完成，三角色皆有自動進食及實際扣糧，空盆補充與存檔重載成功，例外、卡住、導航失敗與接近逾時均為零。此輪尚缺貓咪照顧與貓狗吊球等完整覆蓋；預檢完成不是短測通過，正式 600 秒仍要求完整覆蓋。樓梯矩陣目前 51／54 通過，女孩 150% 的三個案例仍超過 2 DIP 圖片足點誤差門檻；不得以放寬門檻替代修正。

內建診斷檢查的是已安裝程式的場景、持續運行與保存重載；它不需要 SDK，也不等於開發者的建置／單元測試／正式發行門檻。托盤完成通知不會自動喚醒 Codex。
