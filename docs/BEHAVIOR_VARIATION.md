# 參數化行為與風格學習

本次以擴充方式保留四種大腦模式、Fly 與 Connectome 學習、五秒 eligibility trace、原子存檔與原有測試。不使用 LLM、網路服務或文字 token 模型。

## 資料流

大腦選擇動作 → BehaviorDecoder 將目前模式的高階輸出、生理狀態、個性、動作／情境偏好與近期獎勵解碼 → BehaviorParameters → 繪畫、組句、移動、玩具與社交呈現。

Utility、FlyInspired、RealConnectomeExperimental、Hybrid 沿用既有來源選擇與備援；Hybrid 的風格輸入包含混合後的真實連接網路輸出，不重新計算或改寫 Connectome。參數在每次動作開始時取樣並固定，避免每個影格抖動或作品被反覆重畫。隨機種子可重播，原生視窗及拖曳仍由既有控制器處理。

## 參數與輸出

- StyleDrives：創意、新奇、對稱、複雜、社交、調皮、愛玩、平靜與探索。
- DrawParameters：元素數、長度、曲率、方向、對稱、大小、複雜、密度、角落傾向、幾何／符號偏向與主要 primitive。
- 程序繪畫使用線、弧、圓、橢圓、螺旋、多邊形、點、眼睛、嘴巴、愛心、星星，透過縮放、旋轉、鏡射、連接與重疊生成。最多 64 筆、4096 點，作品限制 240×200；保留原來七種圖案以讀取舊存檔。
- WriteParameters 與 ComposableText：情緒、意圖、主詞、動詞、物件、修飾與結尾片段組合。短／長、直接／含蓄、俏皮／平靜、情緒／中性控制實際句式，不呼叫 LLM。文字上限 100 字。
- MovementParameters：速度、單段距離、停頓、轉向、偏角落、游標距離、玩具興趣及彎曲路徑。沿用每次移動最多 0.1 秒的防瞬移限制。
- PlayParameters：推力、彈跳。SocialParameters：接近、觀察、跟隨後停止、繞行、附近坐下、躲一下探頭、等待。懲罰後新動作短暫增加距離；不打斷生理安全睡眠。

## 學習與新奇偏向

每個 trace entry 附上該次實際使用的不可變參數。獎勵按原有時間信用分配同時更新動作、神經網路與風格；不會把目前新參數錯套到舊行為。

DrawStylePreference、ShapePreference、TextStylePreference、MovementStylePreference 使用緩慢有界更新，權重限制 ±0.75。畫風可學對稱、複雜、幾何、密度、大小、位置及主要形狀；文風可學長度、直接、俏皮與情緒；活動可學速度、角落與親近程度。拖曳、暫停、隱藏及過期 trace 不訓練風格。作品全數保留且額滿時不產生作品，也不把未實際產生的作品參數當作風格訓練樣本。

RecentOutputHistory 最多 64 筆，30 分鐘內的自產內容；重複樣式以時間衰減降低取樣分數，近期動作及主要圖形另有軟性降權。組句最多重試 24 次，避免最近相同句子與句型，仍保留有界退路而非永久禁止。沒有記錄使用者的文字、檔案或桌面內容。

## 保存與相容

LearningState.Variation 是可選的新欄位，舊 schema 1 學習與 schema 2 organism 不需重設；缺欄位時使用中性偏好。CreativeWork.Drawing 保存實際生成筆畫，重新啟動不會重新隨機變形。所有新增欄位有數值、長度與容量檢查，沿用 atomic + .bak；未知或損毀存檔不靜默覆寫。

## 驗證與限制

135 項 .NET 測試通過。新增測試覆蓋：大腦輸出對參數的因果影響、300 個可重播且互異的有界圖畫、2000 次組句中超過 1500 種不同文字、最近輸出防重複、相反獎勵訓練後的畫風／文風／速度／距離差異及重載一致性、過期 trace、舊資料與損毀資料、社交距離與停頓。

WPF 冒煙測試另驗證生成圖與文字實際加入畫面、完整作品與近期記憶保存重載；generative-check.png 僅渲染自行生成的向量作品，不擷取桌面。

受控模擬能證明相同輸入在不同獎勵歷史下產生不同風格；尚未證明真實使用數天的人格穩定性，也不代表生物意識。文法與美術為本機程序近似，仍需要使用者長期體驗調整。
