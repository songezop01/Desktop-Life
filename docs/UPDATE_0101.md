# Desktop Life 0.10.1：可靠性與效能收斂

由已安裝的 0.10.0 延續；本版固定功能範圍，集中處理存檔、角色生命週期及復原。工作目錄保留原有修改，schema 維持 v6，三角色資料與美術不改格式。

## 已完成驗收與安裝

- 一般照顧、房間操作與每分鐘保存先複製完整狀態，交由單一背景寫入器做驗證、序列化、備份及原子替換。最多保留一份尚未開始的快照，連續操作合併至較新狀態；合併請求只有較新狀態寫入成功後才完成。
- 快照擁有自己的學習字典、需求歷史、人格證據、繪畫點陣列、房間及次角色資料，背景執行不讀取持續變動的 UI 狀態。捕捉時間、背景寫入時間與等待到持久保存的時間分開量測。
- 正常退出先停止需求、決策、角色物理與操作，再等待最後保存。寫入失敗會保留可操作視窗與先前有效存檔；正常圖示恢復仍在保存成功後完成。首次啟動、系統 suspend／session ending 及隔離診斷保留必要的同步持久化確認。
- 隱藏、暫停、拖曳及佈置中的角色按普通線上需求計算，不從舊睡眠／玩耍意圖取得收益。真正落地睡眠及物理接觸才計入相應活動；隱藏取消舊序列、排隊操作及占用，重新顯示從閒置開始。離線有限休息規則不變。
- 升級／復原使用原生資料目錄與交易快照；中途失敗自動補償資料、安裝紀錄及捷徑原始內容。持續磁碟／檔案鎖等使補償無法完成時，保留驗證過的原快照並明確記錄失敗，不宣稱復原成功。
- 重疊家具高度相差數個像素時，短暫失去支撐先由重力落穩原平台，不提早進入遠處下落階段；保留真實落地、導航復原與超時檢查。
- 隱藏、佈置及舊活動結束時保留尚未完成的安全恢復；重新顯示後先落穩及逃離，再接受下一個活動。隱藏仍清掉舊活動、排隊操作及占用，停止期間不累計恢復演出時間，也不算恢復成功。
- 作品筆畫共用凍結的向量繪圖層，減少每次更新重建的 WPF 圖形與布局物件；保留便條文字、作品保存、隱藏及清除功能。

## 驗收規則

核心與原生 WPF 回歸要驗證三角色、保存失敗、UI 在背景保存時仍回應及退出重試。復原故障測試全部使用隔離資料，包含真實 Windows 捷徑，不在正式歷史上演練降版。

完整驗收須包含十分鐘 All 三角色與至少 7,200 秒原生 WPF 長測，原始導航失敗／恢復、存檔及重載、CPU、配置、工作集、私有記憶體、GDI／USER／視窗資源均保留。長測另加入有界家具變更及作品保留／清理循環。UI 延遲 P50／P95 是派送延遲的區間上界，不等於 FPS。

前後效能比較使用同一台機器、同樣的 45 秒閒置及 60 秒 Both 場景；0.10 已複製為有雜湊的獨立基準，與新版測量依序進行。兩小時場景不能拿來與 60 秒雙角色數據直接比較。真實混合 DPI、拔插螢幕與硬體休眠仍依實測證據接受。

0.10.1 的正式升級入口要求本次來源雜湊一致且 Full PASS。完整驗收、量測數字與安裝位置以當次報告為準；本文件記錄實作及門檻，未跑完的長測不算通過。
