# Desktop Life 0.10 — 插畫陪伴與邊牧犬

這是從 0.9 工作狀態延續的第一個升級里程碑。優先處理角色美術、邊牧犬與可重現的家具導航卡住問題。完整家具插畫、所有方向的連續動作仍在後續計畫。

## 可以使用的改變

- 女孩、橘貓、邊牧犬使用原創透明水彩插畫圖集。女孩另有電腦、閱讀、積木、梳頭與寫字活動圖集；共四張圖集、32 個姿態。主控台採用奶油紙色、粉紫與可可色，點角色卡片即可選擇陪伴。
- 可以只顯示其中一個角色、橘貓與女孩，或三個一起顯示。每個角色的名字、需求、性格、關係、回憶、家具偏好與位置獨立保存，共用房間、玩具及作品展示。
- 邊牧犬不使用人類創作、貓抓板或貓專屬睡眠流程。照顧、改名與回憶區跟隨目前選擇的角色，切換角色不覆蓋原有歷史。
- 修正離開書桌邊緣時下降流程與落地確認互相重設，導致卡在空中的問題。跳躍途中支撐家具被移除時，經重力落地及導航恢復流程處理。
- 修正高紙箱下降至睡墊時橫向距離超出實際能力，以及地板目標被近地平台誤判的問題。下降先選擇可落穩的垂直路線，再步行或跳至下一層；跳躍規劃也檢查下降途中的支撐物。
- 路線規劃涵蓋物理碰撞的 5px 接觸容許區間，避免落到重疊家具；近地紙箱到地板也使用明確下降。刻意停下觀察或休息，不再當作走路卡住；真正無法前進仍會啟動恢復。
- 重設位置跟隨目前選中的角色；照顧被拒絕時保持原暫停狀態，隱藏主角色不自行迎接或發出角色音效。
- 隱藏的診斷內容停止反覆重建；診斷顯示降至每秒一次。音量即時生效，停止拖曳後才寫設定；隱藏的次要角色不再維持高頻動畫計時器。
- 角色圖片解碼與透明命中資訊共用快取。執行時限寬解碼、獨立凍結姿態圖片，避免每個姿態保留整張原圖解碼器。

## 存檔與升級

存檔格式升為 v6，保留並遷移 v2／v3／v4／v5 的舊狀態。舊 0.9 會拒讀 v6，防止舊程式無聲丟棄第三角色。安裝前正常結束舊版，完整備份資料與先前安裝資訊；新版使用獨立版本資料夾。回到舊版需還原升級前存檔，不可直接用舊程式開新存檔。

真實桌面圖示仍沿用備份與恢復保護。測試使用獨立資料，不移動真實圖示。

## 驗證與界線

當次建置、測試、WPF 視窗與十分鐘壓力測試，以 `artifacts/verification/latest/verification-summary.md` 為準。相同場景的前後效能數據與執行檔雜湊記錄於 `artifacts/verification/0.10/PERFORMANCE.md`。短測不能證明長期沒有記憶體洩漏；CPU、配置量與記憶體須分開判讀。

問題優先級、已修正案例與後續完成條件見 [問題追蹤](ISSUES_010.md)。

插畫目前是有限姿態動畫：呼吸、兩幀走動與鏡像轉向，不是完整分層骨架。貓精確撥球及抓板接觸仍使用原有程序式骨架；這些情境存在風格差異。家具及部分道具仍是原有向量。完整美術替換與更連續的演出見 [升級路線](UPGRADE_ROADMAP.md)，不以本版冒充已全部完成。
