# Desktop Life 0.11.0 更新

日期：2026-10-08。狀態：發行驗證通過；實際安裝與備份結果另見主機安裝紀錄。

## 可見變化

- 小屋選單提供一層、兩層、三層固定範本。樓板與樓梯自動配合活動螢幕，家具可跨樓層配置；樓板與樓梯不提供自由編輯。套用時等待角色安全落地。
- 女孩、橘貓、邊牧的設計高度為 256、80、104 DIP，三者共同縮放；坐下自然變矮，保持腳底支點。
- 每位角色使用 8 幀行走及 4 幀坐下／反向起身。步態跟實際位移同步，起身時暫停平移，轉身與呼吸有插值。
- 19 種家具／道具改為溫暖奶油與淺木色插畫，具有實際支撐線與前景接觸遮擋。預設球與玩具方塊也採同風格素材。
- 主螢幕與 spacedesk 間的座標依原生視窗與即時 DPI 計算；螢幕暫時不可用時保留原偏好，回復後可重新使用。

## 可靠性與資料

樓梯採連續腳底支撐及通行預約；隱藏、暫停、拖曳與佈置仍保留安全恢復。修正長路線持續行走卻在 20 秒被判卡住、角色縮放後玩具超出前爪可及範圍，以及不同身高導致同地面角色不避讓。舊存檔玩具會回到新樓板上；導航按距離選擇腳底支撐面，避免把紙箱內底當成樓板，並讓小比例下不足一個畫面單位的落差也能正常離開。站立活動改用家具所屬樓層的真實樓板高度，避免家具稍微移高或移低便走錯樓層、無法開始活動；椅子與床維持真實座面，桌椅配對限定同一樓層。

外層存檔升至 schema 7，保留原角色名字、歷史與家具 ID；遷移涵蓋 v2–v6，未來版本拒讀。安裝前需正常退出、完整備份及保存回復紀錄。回到 0.10.1 必須還原升級前備份。

## 目前限制

睡眠與其他活動仍沿用 v1 原畫，這一版並非所有動作的完整骨架重製。精確貓爪接觸保留程序式外觀。小螢幕使用三層時整體會縮小；全部家具同時顯示仍受可用工作區限制。一層模式不保證能寬鬆擺放所有家具。

實體 S20 拔插、旋轉及硬體休眠尚未驗證。已完成的中斷測試是顯示器清單變化注入；不能當作實體測試。介面派送延遲不是畫面 FPS，未宣稱固定 60 FPS。
