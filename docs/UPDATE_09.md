# Desktop Life 0.9 — 角色生活與家具

本版使用原有 WPF 向量外觀、UtilityBrain、HomeRoutine、BehaviorSequence。沒有加入網路服務、螢幕分析、鍵盤內容讀取或角色關係系統。

## A–C：檔案與角色規則

核心新增 `FurnitureCompatibility.cs`、`RoomActivity.cs`；擴充 `FurnitureAffordance.cs`、`BehaviorSequence.cs`、`HomeRoutine.cs`、`CharacterCapability.cs`。介面新增 `PetWindow.Activities.cs`、`GirlLifeVisual.cs`、`MainWindow.CharacterLifeDiagnostics.cs`，並接入原本的 Home、Behavior、Presence、RoomWindow、照顧介面及診斷。

先由角色能力和 `CanUse(character, furniture, use)` 過濾，再判斷家具優先序、可達性、占用與個別角色的偏好。女孩不能使用貓床、抓板、紙箱及貓食盆；貓不能畫畫、打字、閱讀、拼積木或在餐桌正式用餐。貓仍可使用書桌表面、書架、床與沙發。

新增家具：單人床、椅子、餐桌、電腦、繪圖本、積木盒、沙發、貓食盆。既有書桌、書架保留。選單提供繁體中文名稱。列舉新值只追加，不更改舊家具編號。

## D–I：角色活動

- 用餐：選擇位置、走近、查看、坐下、擺出餐具、用餐、停頓、收起、起身。女孩優先餐桌＋附近椅子，其次餐桌邊、書桌與椅子；無可用家具時使用可攜餐盤的安全姿勢。貓選食盆，使用嗅聞、吃飯、停頓、舔嘴階段。
- 睡眠：女孩優先單人床，再沙發、椅子與書桌短休息；無家具時坐著休息。床上使用水平躺姿，起身含 SitUp／Stretch／Stand；不再經過 Curl／Knead／LickPaw。貓保持原本睡眠姿勢。
- 整理頭髮：書桌／椅子旁調整，使用窄齒人類髮梳，手到頭側，結束後檢查；不顯示寵物梳毛工具。
- 畫畫／寫字：選擇繪圖本或書桌；使用實體速寫本 fallback。作品只在活動的收尾階段產生，受原有產出冷卻與上限控制。
- 電腦：虛擬螢幕與鍵盤、手部操作，不讀取使用者資料。
- 積木：有限模板，逐步出現積木；不是每塊積木的物理模擬。閱讀使用打開的書本和收尾階段。

活動使用相同的 `BehaviorSequence.Activity`：Notice → Approach → Inspect → Sit/Open → Work → Pause → Check → Close → Stand。目標移動、移除或導航失敗會結束該次活動，不生成未完成作品。既有需求變化、Bond 與照顧冷卻仍沿用既有系統。

## J–L：共享家具與習慣

床分 main／foot，沙發分 left／right，書桌與餐桌分 seat／desktop，書架分 front／shelf；其他家具使用 shared 排他區域。床／沙發睡點分開，重設、隱藏與結束行為時釋放占用。用餐選到附近椅子時同時預約椅子。

每個角色仍持有自己的 Learning.LocationHabits；沒有把原角色的家具歷史複製給另一角色。只在實際活動收尾或落在家具後記錄用途，新增用途通過既有有效值驗證。「忘記家具習慣」按目前照顧對象清除。

## M：存檔

仍為 schema 5，不需要 v6。舊版 schema 4 沿原有升級流程，新增角色不繼承另一角色的歷史。安裝前先正常結束舊版，備份完整資料（排除歷次升級備份目錄），再安裝到新的版本資料夾；不移除舊版。

## N–Q：驗證

以 `artifacts/verification/latest/verification-summary.md` 為當次結果，不能將文件視為通過證明。

新增兼容性、身份錯誤、共享區域、家具配對、活動完整階段、目標遺失、女孩睡眠、家具與個別習慣序列化測試。WPF 短測產生女孩各活動 200% 圖片，測試角色邊界、創作收尾及共享預約；此類確定性步進不算真實時間壓力測試。

Standard 為實際十分鐘雙角色壓力測試。Full 再包含至少兩小時原生 WPF；僅背景啟動，不陪跑。未完成的測試不能稱為通過，資源趨勢不能稱為沒有洩漏。

## R–S：限制與 V0.10

本版為簡化向量姿勢，家具配對依距離而非精密吸附；手部／餐具接觸並非完整人體骨架 IK。閱讀與電腦的家具道具及手持道具並存，沒有同步跨視窗物品搬運。積木完成品為當次活動的有限視覺表現，尚未成為可永久保存的新家具。共享區域避免預約衝突，不是完整身體碰撞或雙角色同步演出。

高解析分層素材、精細椅面接觸、拿取／放回書本的跨視窗動畫、永久積木作品展示與更豐富的共同生活演出延後；不以文字階段替代對這些限制的說明。
