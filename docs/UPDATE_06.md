## D：行為鏈

- 玩耍：注意→轉向→觀察→靠近→準備→蹲伏→伸爪→接觸→恢復→評估；失去興趣便停止，不每個 tick 更换目標。
- 睡眠：選可達休息點→靠近→觀察→坐下→側躺→蜷曲→睡眠→醒來→前後肢伸展→恢復。入睡前不提前取得睡眠恢復。
- 摸摸：注意／低親密猶豫→接受→反應→恢復。手只在接受後出現。
- 自主理毛：觀察→舔爪→洗臉→身體理毛→停頓→有限重複→恢復；不出現人的梳子。手動梳毛：接受→放鬆→依靠→恢復，梳子只在對應階段出現。
- 跳躍：看向落點→蹲伏→物理飛行→接地緩衝。導航無進展、落點消失或失敗時，先落地、停頓，再走向可用出口；靠右牆桌下有專門回歸測試，不以瞬移解卡。

## E–G：關係、個性與注意力

Bond 低於 25 先猶豫、小幅退開；25–64 接受後蹭蹭；65 以上反應更久並靠近。呼嚕機率分為 0.15／0.55／0.9，並非每次必播。介面只呈現關係描述與心情。

Timidity 調整反應時間、靠近速度及退開距離；Curiosity 調整觀察及耳朵微動作間隔；Playfulness 調整玩耍持續時間；Laziness 調整休息距離偏好與最低睡眠時間；Social 與 Bond 影響休息地點靠近游標的傾向。差異有界，不新增人格存檔欄位。

一般機會不打斷序列；照顧、生理需求與安全事件可要求收尾。收尾仍等待落地，高優先中斷不能被低優先刺激覆蓋。玩具／休息點保持目標 ID，消失時安全收尾或退回原地休息。附近高速玩具可吸引空閒或已理毛一段時間的角色，不打斷睡眠及正在接受照顧的貓。

玩具最多連續接觸三次，另受時間／靜止興趣限制。結束後有 25 秒短期冷卻；最多保留 32 件玩具及 32 個休息地點的短期資訊。不持久保存階段或冷卻。

## H–K：驗證

Release 建置 0 警告／0 錯誤；233 項測試全部通過（原 201 項，新增 32 項，沒有刪除舊測試）。独立 win-x64、自含式單一 EXE 的隔離 WPF smoke 通過。新增實際 WPF 回歸涵蓋玩耍爪尖接觸、睡眠完整階段、照顧道具時機、右牆桌下進出及半空移除平台。16 種姿態以 100% 渲染並檢查 150% 支撐像素。隱藏時既有計時器降頻，睡眠且玩具靜止時降至 100 ms；吊球靜止後停止物理積分與畫面位置更新。

45 秒閒置採樣（16 邏輯處理器，42 個樣本）：平均整機 CPU 0.72%、單核心等效 11.50%、最高工作集 234.82 MB；私有記憶體由 124.07 MB 至 117.68 MB。這是單次短時測量，未作相同環境下的版本比較，不能聲稱效能提升或長時無洩漏。

升級前以獨立程序取得實際使用者資料並備份，避免開發環境的 AppData 虛擬化誤讀。保留目前 8 件房間物品及原桌面圖示備份。

## L：限制

導航仍是單向平台與二維支撐平面，沒有桌腿／桌板完整實體碰撞；重疊家具可能沒有完整可行路徑。找不到路時安全退出／休息，不保證每件家具都可達。注意力與休息地點熟悉度不跨啟動保存。

沿用原創向量美術與現有步態，增加行為銜接與微動作，沒有新增水彩貼圖素材。女孩沿用既有動作表現。100%／150% 渲染與座標單元測試不等於不同實體螢幕混合 DPI／熱拔插驗收。短時效能採樣不等於數小時穩定性或沒有記憶體洩漏的證明。

## M：V0.7 最值得做的五個方向

1. 家具碰撞輪廓與通道寬度，改善桌腿、狹窄平台與重疊家具通行。
2. 專用貓科動作素材與過渡曲線，深化舔身體、跳躍伸展及耳尾情緒。
3. 可選擇的長期地點習慣，配套小型有界存檔迁移與忘記習慣功能。
4. 兩至八小時自動壓力場景，量測幀時間、配置量與睡眠／喚醒／房間變動。
5. 混合 DPI 實體多螢幕、熱拔插與無障礙操作驗收，改善縮放與操作提示。
