# Desktop Life：目前產品方向

Desktop Life 是 Windows 本機陪伴寵物。重點是連續、可理解的行為，個性與關係逐步影響互動，讓桌面像寵物居住的房間。

正式管線為 UtilityBrain → ActionSelection／PetAction → BehaviorSequence → PetWindow 物理與導航 → 角色外觀。0.10 普通姿態使用 `CompanionSpriteVisual` 的插畫圖集；貓精確前爪追蹤玩具時保留 `FelineVisual` 程序式骨架。BodyAction 代表意圖，序列管理注意力與階段，物理接觸決定實際施力。微動作使用既有更新迴圈，不以每幀重新抽選高階行為。

果蠅神經、FlyWire、Connectome、硬體負載餵養已停止用於正式產品。ExperimentalConnectome、資料工具、相關測試與舊設計文件保留為歷史研究；不能用其測試數量聲稱產品具有生物大腦。本版本不增加雲端、LLM、鍵盤內容讀取或資料上傳。

維持 WPF、144 DIP 支撐基準、既有重力與顯示器座標；插畫以透明 PNG 的 alpha 連通區域擷取姿態，凍結快取後共用，命中檢查跟隨當前姿態的 alpha。既有四足向量骨架留作貓精確接觸與保底用途。0.10 存檔升為 schema v6，支援完整遷移 v2/v3/v4/v5；原角色歷史完整保留，新增角色只建立自己的預設資料。V0.8.1–V0.9 使用 v5，舊版會在讀取 v6 時拒絕，避免忽略第三角色後於保存時遺失其歷史。回到 0.9 必須使用升級前的完整 v5 備份；不要將 v6 手動改標為 v5。較新未知版本仍拒絕讀取與覆寫。最多 32 筆家具習慣可保存，短期行為、注意力、玩具冷卻與微動作不寫入存檔。桌面圖示互動預設關閉，啟用先備份，提供恢復；不修改原本安全策略。

驗證要區分單元測試、WPF 真實視窗檢查、短時間效能採樣與人工長期體驗。0.10 的插畫是有限姿態圖集，包含鏡像轉向、兩幀走動與輕微呼吸；尚未完成分層毛流、各方向連續動畫、完整家具碰撞體與人體 IK。家具和部分道具仍為向量，貓精確玩具接觸時外觀會切回原程序式骨架；不能宣稱全專案美術已完成。多螢幕實機驗收與長測仍以實際摘要為準。

0.10 增加邊牧犬角色與暖色主控台，視覺方向以使用者提供的三張設定圖為參考；設定圖不直接當作角色貼圖。素材來源與擷取資料記錄在 `src/DesktopLife.App/Assets/Companions/SOURCES.md`，後續分層和家具美術規劃記錄在 `docs/ART_DIRECTION_010.md` 與 `docs/UPGRADE_ROADMAP.md`。

V0.7 Home Update 在原序列、偏好與導航上加入家具語意、紙箱／抓板／睡窩、熟悉度及低頻生活機會。家具沒有貨幣價格、耐久、髒亂或離線懲罰；目標是低壓力陪伴，讓使用者觀察出牠的習慣。

V0.8 在既有管線加入 CharacterCapability：貓保留貓科表現，女孩使用人類塗鴉／便條與安全姿勢。舊作品不重生成。原始 PersonalityProfile 不變，以小型有界 evidence／offset 形成緩慢偏移；最多 32 組成功活動銜接與 6 類真實里程碑均有上限及降頻。Bond 仍表示關係，不等於 Social 特質。

V0.8.1 的 Quick 已納入四人格／六週邏輯模擬與雙角色模型測試；WPF smoke 與長測由獨立 worker 執行，摘要在 `artifacts/verification/latest/`。任何未完成的 Standard／Full 階段仍標示 RUNNING、REVIEW 或 NOT RUN，不宣稱完整長時間穩定性驗收通過。
