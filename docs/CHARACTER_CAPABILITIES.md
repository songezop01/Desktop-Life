# 角色能力與表現邊界（V0.8）

管線：意圖 → CharacterCapability → 既有選擇器／序列 → 角色專屬表現。BodyAction 是意圖，不保證每種外觀都能用同一姿勢。

| 能力 | 橘貓 | 女孩 |
|---|---|---|
| 人類語句、便條、塗鴉 | 禁止新增 | 本機短句、16 種具象模板 |
| 喵叫／呼嚕 | 保留 | 不播放 |
| 抓板、舔爪洗臉、貓式踩奶 | 貓科向量表現 | 坐姿／觀察／伸展備援 |
| 社交 | 觀察、靠近、蹭蹭、聲音 | 氣泡與既有人類姿勢 |
| 休息／睡眠 | 現有四足骨架與蜷睡 | 既有坐／躺姿，沒有新女孩骨架 |
| 舊作品顯示 | 保留 | 保留 |

ActionSelection 在計算偏好前過濾角色能力；PetWindow.SetAction 對不適合的創作意圖退回探索；ArtWindow.Create 再檢查角色。Say 只允許女孩。切換外觀清除不相容的序列、排隊意圖與氣泡，並中斷尚未完成的轉換學習。女孩可以經過共用序列時序，但不顯示貓專屬幾何或播放呼嚕。

貓咪的 CareStatus 是系統描述，不是牠說的人話。UI 的親密關係措辭不把高 Bond 直接稱為黏人。進階診斷可查看能力、原始／有效人格、偏移及習慣；一般畫面只顯示文字觀察。

GirlDoodleGenerator 輸出既有 GeneratedDrawing，DoodleTemplateId 是 optional metadata。舊 Drawing 直接顯示既存線條；沒有 Drawing 時仍走舊 Pattern renderer，不重新生成舊作品。模板有小角度旋轉、輕微抖動、尺寸與裝飾差異，沒有隨機多邊形混合。舊 ProceduralDrawing／ComposableText 保留歷史相容及原測試，但正式新作品使用 Girl 模板路徑。

V0.9 可補女孩專屬手部接觸、招手、閱讀等美術；V0.8 不新增完整女孩動畫系統。能力邊界先前已有單元與 WPF 檢查，後段整合依使用者要求未重跑驗收。
