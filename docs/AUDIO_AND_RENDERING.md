# 音效與畫面更新

音效會在 `%LOCALAPPDATA%/DesktopLife/audio-v1` 建立 `Meow.wav`、`Purr.wav`、`Bell.wav`。若要替換音效，建立 `audio-v1/custom`，放入相同檔名的單聲道或立體聲 WAV；下次啟動會優先使用自訂檔案。程式不會上傳音效，也不會覆蓋自訂檔案。

控制台可分別調整總音量、貓咪音效、玩具音效和環境音效。現在的環境音效分類預留給房間環境聲，尚未加入背景音樂。女孩不播放角色音效；橘貓會在招呼／吃飯時喵叫，摸摸／梳毛／蹭蹭時呼嚕，鈴鐺球受碰撞或拋動時發聲。每種聲音有冷卻時間，避免連續碰撞變成噪音。

橘貓使用獨立四足向量骨架，包含後腿、肩背、頭部、耳朵、眼睛、瞳孔、尾巴與鼻口。眼睛會追蹤游標，瞳孔會隨視線偏移，耳朵依動作輕轉；跑步、伏低、蜷睡、伸爪、梳毛和吃飯使用貓科姿勢。女孩保留原本的人形動作。

0.4 家具前後排序依接地位置更新，支撐中的平台在角色後方，排序相同時不反覆呼叫原生重排。家具仍是獨立透明視窗，編輯模式可拖曳，平時點擊穿透。方塊採 64×64 透明視窗容納 40×40 碰撞物件的旋轉和拿起縮放；單純 ClipToBounds=false 無法擴大原生視窗，舊版設定不足以排除裁切。不同顯示卡的實際合成效果仍需持續驗證。
