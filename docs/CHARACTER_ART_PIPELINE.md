# 角色美術管線：0.10 插畫圖集與後續分層

## 0.10 實作方向

`CompanionSpriteVisual` 接入透明 PNG 姿態圖集。邊牧犬、橘貓、女孩基本素材各有 8 個獨立姿態；不是按固定像素格線切圖，而是以 alpha ≥ 24 的四向連通區域擷取，再將上、下兩排各 4 個姿態依左右排序。擷取的位圖凍結並快取，在角色與主控台預覽間共用；每個圖集使用共同縮放率與 `y = 144` 支撐基準。命中檢查使用當前姿態的 alpha，配合鏡像與呼吸變換還原座標。

基本素材、來源與擷取資料見 `src/DesktopLife.App/Assets/Companions/SOURCES.md`；色票與驗收規則見 `ART_DIRECTION_010.md`。這些檔案說明實作與素材契約，不代表所有驗證已完成。

普通姿態使用插畫。貓精確前爪追蹤玩具時，仍保留 `FelineVisual` 程序式四足外觀和接觸邏輯；原有家具、玩具與部分道具仍是向量。女孩另有 8 姿態活動圖集，提供電腦、閱讀、積木、整理頭髮、寫字、休息、伸展與側躺睡眠素材；活動道具隨姿態繪入，尚未與家具做精確手部接觸或跨視窗搬運。完整分層、更多視角、接觸關鍵幀、家具插畫與人體 IK 尚未完成。沒有導入 Live2D、Spine、Unity 或其他新引擎。

## 後續分層角色規格（規劃）

V0.7–V0.9 使用 WPF 原創向量與 FelineVisual。以下保留當時規劃的分層交付契約，作為 0.10 圖集之後的升級要求，不代表目前圖集已實作這些骨架功能。

## 圖層

| 圖層 | 分件與用途 |
|---|---|
| Body／Head | 胸腹、背部、頭、下顎；可分前／側／後視角 |
| FrontLeg／BackLeg | 左右與遠近側分件；肩／髖、肘／膝、腕／踝、爪端 |
| Ear L/R／Tail | 各耳獨立轉向；尾根與有限中段，避免高成本毛髮粒子 |
| Eyes／Pupils／Mouth | 眼白／眼皮、瞳孔、嘴與舌；閉眼和瞳孔變化不改命中區 |
| Accessory／Shadow | 可選配件；影子独立、不攔截滑鼠 |

圖層名稱、左右命名與前後視角必須一致。素材須為原創或授權明確；保留作者、來源、授權與可再分發範圍。不得從參考搜尋畫面直接擷取角色圖。

## 座標與接觸契約

- 沿用邏輯框 116 × 144 DIP，支撐基準 y = 144。高解析圖以相同邏輯尺寸定位，不用貼圖像素尺寸改動物理身高。
- Anchor 表示角色根、頭部、肩、髖、耳根、尾根；Pivot 是圖層實際旋轉點，需記錄相對 Anchor 的座標。
- Contact Point 至少包括四爪、鼻端、身體支撐、可互動前爪。爪尖接觸由物理目標提供，不能靠變換整個角色來假裝接觸。
- 畫面呼吸、毛流與頭動不得上下移動所有支撐點。站姿、蹲坐、側躺、蜷曲各自定義有效支撐點集合。
- Z-order：遠側腳／尾、軀幹、近側腳、頭、臉與配件。紙箱等外部遮擋保持在房間層處理，不能把家具畫死到角色貼圖。
- 命中區跟隨可見形狀與 clipping；透明邊距、影子與完全被遮住的部分不得攔截滑鼠。

## Pose 與 Transition

BehaviorSequence 表達意圖與階段；Character Expression 將同一意圖映射到角色姿態。貓的舔爪、抓板、呼嚕、踩奶不可硬套女孩。缺素材時使用站立、坐下、觀察等 Generic fallback。

每組素材需交付：準備、接觸、保持、收尾的關鍵姿態；標註支撐腳與移動腳、爪端位置、表情、耳尾限制及可接受插值範圍。轉身要提供正／側／背的對應關節，避免鏡像翻轉時伸爪穿過物件。

## 驗證門檻

未來素材先在 100／125／150／200% DPI 檢查清晰度、透明邊界、支撐點、箱內遮擋與爪端接觸，再接入完整角色。量測相同場景的幀時間、配置量、貼圖記憶體及載入時間；不得僅憑截圖宣布效能合格。素材缺失須退回既有向量角色，不得使存檔或房間無法載入。

## V0.8 角色意圖映射

新增素材必須遵守 CharacterCapability，不能藉動畫素材繞過創作／語言限制。貓用耳、眼、尾、姿態與叫聲；女孩創作使用可辨識模板和人類手部意圖。共用序列階段是時間控制，不要求共用舔爪、抓板或踩奶姿勢。女孩缺少接觸素材時保留 Generic fallback，V0.9 再擴充；不可將貓骨架硬套人類。
