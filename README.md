# Desktop Life · 螢幕小屋 0.12

0.12.0 候選版已完成功能收斂，改用家具食物、自主進食、直接撫摸與拖梳子照顧，並改善貓狗吊球、行走與樓梯落腳。正式 Full 驗證與安裝尚未完成；操作見 [0.12 更新](docs/UPDATE_012.md)，驗證狀態見 [0.12 開發證據](docs/DEVELOPMENT_012.md)。

目前已安裝與公開發行的穩定版仍是 0.11.1，原有 Standard 驗證與安裝證據見 [0.11.1 更新](docs/UPDATE_0111.md) 與 [安裝核對](docs/INSTALLATION_0111.md)。以下操作說明對應 `codex/012` 的 0.12 候選版。

住在桌面的小夥伴。Windows 11 x64、本機運作，使用照顧需求、個性、親密度與活動偏好決定行為。橘貓「栗子」、女孩與邊牧犬各有自己的狀態和回憶，共用一個房間。已停止果蠅／FlyWire 神經方案，不再以電腦負載餵養。

0.11 將螢幕變成可選一、二或三層的小屋，三位朋友經由樓梯使用上半部空間。加入 8 幀走路、4 幀坐下／起身、合理的人與動物比例，以及 19 種溫暖居家家具插畫。詳見 [0.11 更新](docs/UPDATE_011.md)、[升級路線](docs/UPGRADE_ROADMAP.md) 與 [驗證流程](docs/VERIFICATION_WORKFLOW.md)。0.11.0 已通過 611 項測試、短測與兩小時長測，並完成原生安裝核對，見 [安裝紀錄](docs/INSTALLATION_011.md)。

0.10.1 已通過439項測試與兩小時三角色驗收並完成安裝，修正背景存檔、安全退出、導航恢復與作品繪製負擔。詳見 [0.10.1 更新](docs/UPDATE_0101.md)。

## 開始陪伴

公開下載：[GitHub 最新版本](https://github.com/songezop01/Desktop-Life/releases/latest)。下載 `DesktopLife-<版本>-win-x64.zip` 並解壓縮；`SHA256SUMS` 提供檔案核對值。GitHub 自動建置包會標示對應原始碼，與本機驗收包各有自己的雜湊。

雙擊桌面或開始功能表的「Desktop Life 桌面寵物」，或直接開啟發行包的 `DesktopLife.exe`，不需要 CMD、Codex 或另裝 .NET。關閉 Codex 不會結束從捷徑啟動的桌寵。首次建立角色預設為橘貓「栗子」；更新既有存檔保留原角色的性格、作品及偏好，新角色建立獨立資料。升級流程見下方「資料與升級」，開發建置見 [開發方式](docs/DEVELOPING.md)。

- 點上方角色卡片選擇朋友，或在選單選擇共同陪伴；每位朋友的改名、狀態、關係與回憶獨立保留。
- 放置飼料碗或餐桌，再點家具食物區選擇飼料或料理。角色餓了會自行前往，吃一口減一份；空了需要補充。
- 游標靠近角色露出的頭髮／毛皮會顯示小手，輕輕移動才算撫摸。拖動花朵木梳接觸毛髮可梳理；照顧右鍵與控制台照顧對象已移除。
- 按住角色可抱起，球類玩具可直接拖動；貓跳台吊球也能點選與拖撥。疲累時角色自行休息，照顧有短暫冷卻。
- 安靜陪伴讓牠以休息、梳毛和伸展陪你工作，停止追游標；選項會保存。
- 你離開一陣子再回來，牠會打招呼。關閉程式期間牠會休息，最多計算八小時，不扣親密度。
- 「我們的小回憶」最多保留 30 則，含最多 6 則真實生活里程碑，顯示最近 6 則。一般照顧摘要每 30 分鐘最多一則。親密度逐步改變關係描述和親近傾向。
- 最小化收到托盤；雙擊托盤回到小屋。按 X 預設進入托盤；可選擇直接退出。托盤「結束」會保存並退出。

## 外觀與動作

三個角色採用新生成的透明水彩插畫。橘貓保留虎斑、奶油白胸腹與鈴鐺；邊牧犬有黑白長毛、白胸白爪、粉色項圈與金色吊牌；女孩有栗棕長髮、花飾、奶油色開襟衫與居家鞋。原有姿態及女孩電腦、閱讀、積木、整理頭髮與寫字活動素材保留，另加入三角色走路及坐下／起身片段。原始參考設定圖只提供方向，不直接當作貼圖。來源見 [素材記錄](src/DesktopLife.App/Assets/Companions/SOURCES.md)。

走路以每角色 8 幀配合實際位移，坐下及起身各有四個連續畫面，轉向與呼吸採插值。女孩、橘貓、邊牧的設計高度為 256／80／104 DIP，小螢幕共同縮小。睡眠與其他活動仍沿用原有有限姿態；貓精確撥球、抓板接觸保留程序骨架。完整分層與更多方向仍屬後續工作。貓和犬以姿態表達，女孩可使用短暫氣泡。

## 角色與共同生活

角色選單提供只顯示橘貓、只顯示女孩、橘貓與女孩、只顯示邊牧犬、三個角色都顯示。每個角色的名字、需求、人格、關係、回憶、家具習慣與位置獨立保存，共用房間、玩具與作品展示。女孩可畫畫、寫字、閱讀與使用電腦；邊牧犬使用適合犬類的照顧、玩耍與休息，不使用人類創作或貓抓板流程。

「佈置牠的房間」可選擇一、二或三層固定小屋，最多三層。樓板與樓梯由程式配置；可按「重新安排家具」分散物件，或開啟佈置模式拖曳家具、右鍵收起。更改樓層會等角色安全落地。女孩使用單人床、椅子、餐桌、書桌與活動道具；寵物使用各自允許的休息與玩具位置。家具支撐與導航保持原有模型，尚未成為完整家具碰撞或同步雙角色演出。

## 桌面共處

四級顯示：最高、全螢幕時隱藏、全螢幕與最大化時隱藏（預設）、桌布層級。角色、作品和玩具同步套用。最高層級不保證覆蓋獨佔全螢幕或 Windows 安全桌面。

真實快捷圖示互動預設關閉，啟用後先備份再移動；控制台與托盤可一鍵恢復，正常退出嘗試恢復，異常中斷於下次啟動重試。詳見 [圖示恢復說明](docs/DESKTOP_ICONS.md)。

## 資料與升級

資料留在 `%LOCALAPPDATA%/DesktopLife`，每 60 秒與正常退出保存。0.12 使用存檔 schema v8，遷移 v2–v7 並保留角色、樓層與家具；舊存檔的食盆／餐桌從空庫存開始。回到 0.11 或更早版本須還原升級前的完整備份及對應程式，不可手動改寫版本號。較新未知版本拒絕讀取與覆寫。舊神經資料欄位僅為相容保留，不參與行為決策。程式只讀游標位置與閒置時間，不採集硬體負載、不讀鍵盤內容、不上傳資料。

首次 0.12 升級使用 `scripts/upgrade-012.ps1 -VerificationDirectory <Full 已通過的驗證目錄>`：核對相符驗證與來源，產生發行包並完成封裝原生檢查、安全結束舊版、核對完整資料備份與回復入口，再安裝到新版本資料夾。該入口只接受正式 0.12.0 的 Full PASS；後續同系列修補依 Standard 政策處理。

## 開發與驗證入口

- `scripts/build.ps1`：建置與單元測試。
- `scripts/publish.ps1`：產生 `artifacts/standalone/<版本與建置時間>/DesktopLife.exe` 與 ZIP，不附帶 FlyWire 資料或實驗組件。
- `scripts/install.ps1`：底層檔案安裝與捷徑工具；正式更新使用上述安全升級入口，以免略過資料備份與驗證。
- `scripts/stress.ps1 -Seconds 600 -Floors 3 -OutputDirectory artifacts/verification/0.12`：隔離存檔的 10 分鐘房間壓力測試。
- `DesktopLife.exe --smoke-test`：隔離存檔的 WPF 互動、保存、顯示層級及美術檢查。
- `scripts/verify.ps1 -Mode Quick|Standard|Full`：同系列小更新預設 Standard（含十分鐘短測），跨 minor 如 0.11 → 0.12 才安排 Full；明示停止優先。Standard／Full 由獨立程序執行，摘要固定在 `artifacts/verification/latest/`。
- `Quick Verification.cmd`／`Full Verification.cmd`：不熟悉 PowerShell 時可直接雙擊啟動驗證。

舊實驗原始碼、資料及研究文件保留供歷史追溯，非目前產品功能。舊版使用說明見 `docs/LEGACY_V01.md`。混合 DPI、多種 Explorer 版本、長期自然養成仍需持續使用驗收；短測不證明長期沒有洩漏。

## 歷史更新紀錄（0.3–0.8.1）

以下保留各版當時的功能與驗證記錄。版本、存檔 schema、測試數及外觀描述不代表目前 0.11 的最終結果；當前方向與驗證請以上方連結為準。

### 重力與房間佈置（0.3）

角色與玩具放開後會受重力落下，地板為 Windows 工作區下緣（工作列上方）。玩具有反彈、摩擦與互撞；點擊力由接觸位置指向中心，點左往右、點右往左，正中心輕點則向上彈起；拖曳放手沿手勢速度拋出。

小屋「佈置牠的房間」可放置貓跳台、溜滑梯、書桌、書架、睡墊、毛線球、鈴鐺球、玩具老鼠、紙箱、貓抓板與睡窩，最多 24 件。開啟佈置模式可拖家具、右鍵收起，完成後關閉佈置模式，家具就不攔截桌面點擊。新增玩具可直接拖曳，右鍵收起。

家具為固定支架，有可落腳的平台；斜面會讓角色與玩具滑下。寵物可跳上接近且可到達的平台，也可由你抱上去。這是單向平台物理，不是完整室內牆面或家具積木模擬。房間及玩具位置隨存檔保存。

玩球改為從側邊靠近、伸爪後才施力；使用者梳毛有梳子，摸頭有人手，自主理毛使用貓爪。圖示的長期備份恢復後不刪除，按「更新備份為目前排列」可主動替換基準。

### 貓咪與跳台（0.4）

貓咪腳底與平台共用接觸高度，抱起後落地會恢復站姿。跳台的吊球有固定繩長、慣性與阻尼；陪玩時會輪流選擇地面玩具和跳台吊球，從下層平台伸爪撥球。一般家具仍穿透滑鼠，吊球主要由貓咪互動。

家具依接地位置排序，平台支撐角色時保持在角色後方。方塊視窗預留旋轉及拿起時的透明邊距，裝飾與玩具一起轉動。詳見 [本次更新與驗證](docs/CAT_ROOM_UPDATE.md) 和 [後續改善建議](docs/REVIEW_2026-09-19.md)。

### 0.5 更新與開發

本版加入存檔復原、平台導航、選擇房間螢幕、音效包管理與新貓科姿態。詳見 [更新內容與驗證界線](docs/UPDATE_05.md)、[開發方式](docs/DEVELOPING.md) 和 [音效包格式](docs/SOUND_PACKS.md)。

### 0.7 家具習慣與相容性

新家具可直接在房間選單放置。偏好讓牠比較常選熟悉位置，近期重複會降權，因此有床也可能睡紙箱。進階區「忘記家具習慣」只清地點習慣，保留名字、關係、回憶與其他資料。

V0.6 的 v2 存檔會遷移為 v3，保留原子保存及三代備份。舊版 EXE 會拒絕新檔；若要降版須先保存新檔並還原升級前備份。詳見 [Home Update](docs/UPDATE_07.md) 與 [未來美術規格](docs/CHARACTER_ART_PIPELINE.md)。

### Individuality Update（0.8 / 0.8.1）

貓咪不再產生人類文字與塗鴉；舊作品保留。女孩的新塗鴉使用 16 種可辨識模板。原始人格不變，真實互動可慢慢累積小幅學習偏移；成功完成的活動、家具熟悉度與關係共同影響下一步。「牠最近的樣子」只顯示簡短描述，數值放在進階診斷。

存檔 schema v5 可遷移 v2/v3/v4。原有角色歷史完整保留，新增角色只建立預設資料；回到舊版需使用升級前備份。新版不自動安裝或改動真實存檔。

V0.8.1 提供 Quick／Standard／Full 驗證入口。Quick 會執行 Release build、316 項單元測試、四人格／六週邏輯模擬及 Dual Presence model tests；Standard／Full 在獨立程序執行 WPF smoke、短 stress 與原生 soak，完成前摘要保持 RUNNING。完整實作、限制與結果見 [V0.8.1 報告](docs/UPDATE_08_1.md)。
