# Desktop Life · 陪伴房間 0.5

一隻住在桌面的小寵物。Windows 11 x64、本機運作，使用照顧需求、個性、親密度與活動偏好決定行為。已停止果蠅／FlyWire 神經方案，不再以電腦負載餵養。

## 開始陪伴

雙擊桌面或開始功能表的「Desktop Life 桌面寵物」，或直接開啟發行包的 `DesktopLife.exe`，不需要 CMD、Codex 或另裝 .NET。關閉 Codex 不會結束從捷徑啟動的桌寵。首次建立角色預設為橘貓「栗子」；更新既有存檔會保留外觀、性格、作品及偏好，可自行換橘貓或改名字。安裝／建置方式見 [獨立發行說明](docs/DISTRIBUTION.md)。

- 控制台「餵飯飯、摸摸頭、一起玩球、梳理毛毛、哄牠睡覺」會實際影響需求與親密度。
- 輕點角色給牠摸摸；按住拖曳可抱起，右鍵打開照顧選單。圓球與方塊也能拖曳。
- 飽了會拒絕點心，太累會拒絕陪玩；照顧有短暫冷卻，不需一直連點。
- 安靜陪伴讓牠以休息、梳毛和伸展陪你工作，停止追游標；選項會保存。
- 你離開一陣子再回來，牠會打招呼。關閉程式期間牠會休息，最多計算八小時，不扣親密度。
- 「我們的小回憶」保留最近 30 次照顧，顯示最近 6 則。親密度會逐步改變關係描述和親近傾向。
- 最小化收到托盤；雙擊托盤回到小屋。按 X 預設進入托盤；可在小屋選擇直接退出。托盤「結束」一定會保存並退出。

## 外觀與動作

橘貓有橘色虎斑、奶油色胸腹、杏仁眼、頰毛與鬍鬚，四足步態、尾巴彎曲、獨立轉耳、追視、瞳孔縮放和眨眼。行走、跑動、伸展、蜷睡、吃飯、梳毛、蹭蹭、招呼、伸爪與落下使用不同貓科姿勢。女孩保留原本外觀。平常以姿態與短暫氣泡表達，不顯示動作標籤。

## 桌面共處

四級顯示：最高、全螢幕時隱藏、全螢幕與最大化時隱藏（預設）、桌布層級。角色、作品和玩具同步套用。最高層級不保證覆蓋獨佔全螢幕或 Windows 安全桌面。

真實快捷圖示互動預設關閉，啟用後先備份再移動；控制台與托盤可一鍵恢復，正常退出嘗試恢復，異常中斷於下次啟動重試。詳見 [圖示恢復說明](docs/DESKTOP_ICONS.md)。

## 資料與建置

資料留在 `%LOCALAPPDATA%/DesktopLife`，每 60 秒與正常退出保存。舊存檔可繼續載入；舊神經資料欄位僅為相容保留，不參與行為決策。程式只讀游標位置與閒置時間，不採集硬體負載、不讀鍵盤內容、不上傳資料。

- `scripts/build.ps1`：建置與單元測試。
- `scripts/publish.ps1`：產生 `artifacts/standalone/<版本與建置時間>/DesktopLife.exe` 與 ZIP，不附帶 FlyWire 資料或實驗組件。
- `scripts/install.ps1`：安裝最新版到使用者程式資料夾，建立桌面與開始功能表捷徑。
- `DesktopLife.exe --smoke-test`：隔離存檔的 WPF 互動、保存、顯示層級及美術檢查。

舊實驗原始碼、資料及研究文件保留供歷史追溯，非目前產品功能。舊版使用說明見 `docs/LEGACY_V01.md`。

詳見 [陪伴版設計與驗證](docs/COMPANION.md)。混合 DPI、多種 Explorer 版本、長期自然養成仍需持續使用驗收。

## 重力與房間佈置（0.3）

角色與玩具放開後會受重力落下，地板為 Windows 工作區下緣（工作列上方）。玩具有反彈、摩擦與互撞；點擊力由接觸位置指向中心，點左往右、點右往左，正中心輕點則向上彈起；拖曳放手沿手勢速度拋出。

小屋「佈置牠的房間」可放置貓跳台、溜滑梯、書桌、書架、睡墊、毛線球、鈴鐺球、玩具老鼠，最多 24 件。開啟佈置模式可拖家具、右鍵收起，完成後關閉佈置模式，家具就不攔截桌面點擊。新增玩具可直接拖曳，右鍵收起。

家具為固定支架，有可落腳的平台；斜面會讓角色與玩具滑下。寵物可跳上接近且可到達的平台，也可由你抱上去。這是單向平台物理，不是完整室內牆面或家具積木模擬。房間及玩具位置隨存檔保存。

玩球改為從側邊靠近、伸爪後才施力；梳理有梳子，摸頭有人手。圖示的長期備份恢復後不刪除，按「更新備份為目前排列」可主動替換基準。

## 貓咪與跳台（0.4）

貓咪腳底與平台共用接觸高度，抱起後落地會恢復站姿。跳台的吊球有固定繩長、慣性與阻尼；陪玩時會輪流選擇地面玩具和跳台吊球，從下層平台伸爪撥球。一般家具仍穿透滑鼠，吊球主要由貓咪互動。

家具依接地位置排序，平台支撐角色時保持在角色後方。方塊視窗預留旋轉及拿起時的透明邊距，裝飾與玩具一起轉動。詳見 [本次更新與驗證](docs/CAT_ROOM_UPDATE.md) 和 [後續改善建議](docs/REVIEW_2026-09-19.md)。
